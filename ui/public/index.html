    Control plane

    Open a shell on the sandbox's AI Gateway or Couchbase node.

    SSM uses aws ssm start-session with your AWS credentials (no SSH keys needed). SSH connects to <NAME>_AIGW_SSH / <NAME>_CB_SSH from .env, or ec2-user@<public DNS>, with SSH_KEY if set. The node is found from its ASG unless the form names its instance id.

    System prompt

    Uses the gateway URL and API key choice from the form (a temporary key is created once and reused for up to an hour). Without a gateway URL, the endpoint found by the last run's control plane lookup is used.
